# 안녕하세요 강원중학교 찾아가는 학교 컨설팅 인문교과 
#1) GIS_STUDIO를 이용한 지리 정보 시각화 분석
#2) 비정형 데이터의 시각화 자료 모음 GITHUB입니다.

## 1) GIS_STUDIO를 이용한 지리 정보 시각화 분석

* 공간에 대한 정보를 담고 있는 데이터는 우리 지역을 파악하고 문제 해결 하는데 큰 도움이 됩니다.
* 그러나 많은 양의 데이터를 효과적으로 다루고 시각화하기에는 많은 도구들과 경험이 필요한데요
* 그것을 쉽게 할 수 있는 프로그램인 GIS_STUDIO를 바탕으로
* 다양한 정보를 지도 상에 효과적으로 표현하고
* 여러 정보를 분석하고 시각화해보겠습니다.
* https://github.com/CarlosQuperman/GIS_STUDIO

## 2) 비정형 데이터의 시각화

* 비정형 데이터는 형식이 정해져 있지 않은 데이터를 의미합니다.
* 텍스트, 이미지, 동영상 등의 데이터가 바로 비정형데이터의 대표적 예시이며
* 생활기록부를 예시로 하자면 과세특, 창체기록, 행발 등이 비정형 데이터의 예시라 할 수 있습니다.
* 비정형 데이터를 다룸에 있어 LLM(대형 언어 모델)의 가치는 높으며
* 이를 활용한 데이터 분석 및 시각화 툴이 어피니티 버블입니다.
* 어피니티 버블에 대한 소개 이후 간단한 실습을 수행해보고
* 교육 활동에 있어 활용 방법에 대해서 고민해보는 시간을 가져 보겠습니다!
* 비정형 데이터 시각화 도구 어피니티 버블 : https://affinitybubble.com/welcome?redirect=/affinitybubble
* 어피니티 버블 활용 과정에서 사용한 텍스트1 : 대통령 취임사 https://www.hani.co.kr/arti/politics/bluehouse/1042216.html
* 구글 제미나이 활용한 텍스트 전처리(제미나이) : https://gemini.google.com/app?hl=ko
* 학생 실습 자료 1 : https://docs.google.com/document/d/1KPerMkZqMGfHTrdJtJ97MBOpta_a5PWvWPMpyk0xo0g/edit?tab=t.0
* 학생 실습 자료 2 : https://docs.google.com/document/d/1YHVwwJi9-nCC9sAu5THZcU5hOQ8iuQY4uQkVPyxf9vE/edit?tab=t.0
* 학생 실습 자료 3 : https://docs.google.com/document/d/1zw8F3GNfIWS3yxsaqc3gOwTC7m7Dy4iWVZsWRwST9OI/edit?tab=t.0
